# 城市与地铁

**简体中文** · [繁體中文](./README.zh-TW.md) · [English](./README.en.md)

**在真实城市里，画出你自己的地铁。**

《城市与地铁》是一款在浏览器中游玩的单人地铁规划与城市经营游戏。从第一座车站开始，连接住区、商圈、校园与机场，跨过江河，逐步织出自己的交通网络。城市随年代发展，居民也会根据你的路网重新选择出行方式。

**[原版在线游玩](https://city-and-metro.pages.dev)** · [原始仓库](https://github.com/VinsonFung/city-and-metro) · [使用许可](./LICENSE.txt)

## 上海社区修改版

基于 VinsonFung 的网页版 v2.7.2。游玩本版可下载分支，在桌面浏览器打开 `index.html`，或在仓库目录运行 `python3 -m http.server 8000` 后访问本地 8000 端口。

- 上海扩展至全市 16 区，地图为 128 × 140 公里，每格 250 米。原有片区沿用开放时间。新增近郊在 2015 年开放，包括吴泾、嘉定新城、宝山和闵行外围、松江东北、青浦东部、浦东机场及周边。其余远郊在 2020 年开放，包括松江和青浦新城、奉贤、金山、南汇及崇明三岛。昆山市花桥镇作为江苏片区，按真实镇界一并在 2020 年开放；其余市界外陆地只作地理参照。
- 2021–2026 年为「后疫情时代」，加入五个新城、疫情与恢复、枢纽客流回升、沪苏湖高铁与机场联络线、地铁延伸及崇明线调试。地铁线路由玩家建设。[五个新城政策](https://www.shanghai.gov.cn/nw12344/20210302/6c8561a91a67478899a5eb51aa612d78.html) · [复运公告](https://www.shanghai.gov.cn/nw12344/20220531/7feab162e2f647e2976dab216102bbee.html) · [2023 年客流恢复](https://english.shanghai.gov.cn/en-Latest-WhatsNew/20240103/3f1ebb5a6da2432aa518b73c4eb14983.html) · [2024 年交通工程](https://www.shanghai.gov.cn/nw4411/20250101/7f97e10f1b0f4a6485d44d8fe9e2806e.html) · [2 号线西延伸](https://service.shanghai.gov.cn/SHVideo/videoshow_933E0E51A7DEB228_0.html) · [18 号线二期](https://www.shanghai.gov.cn/nw4411/20251227/b69b7008d2e647f7a3cab7e160ffe225.html) · [崇明线调试](https://www.shanghai.gov.cn/nw31406/20260917/3207a47b34694050b2afbfbccac9959f.html)
- 2027–2040 年进入「喜迎奥运」。按公布的计划设定上海东站和宝山站，模拟 2030 年获得主办权、2033 年动工、2037–2038 年场馆启用、2039 年测试赛和 2040 年 8 月吴泾奥运会。赛后奥运村转为居住社区。2040 年全市模拟人口基准为 3500 万。[两座枢纽的投运计划](https://www.shanghai.gov.cn/nw4411/20260430/e9961a938b904f89b93178318eebbdb4.html) · [吴泾工业区更新规划](https://www.shanghai.gov.cn/gwk/search/content/9ce0e2a0-ff5a-41c8-9e91-341424340c4c) · [上海七普](https://www.shanghai.gov.cn/nw12344/20210518/001a0cef127c499eb381fa8dc3208e95.html)
- 交通模型自动比较步行和骑车接驳。步行速度为 75 米/分钟（4.5 公里/小时），骑车速度为步行的 3 倍，即 225 米/分钟（13.5 公里/小时）；每段骑行接驳加 5 分钟，最多骑行 15 分钟（约 3.38 公里）。步行覆盖率仍按步行计算。
- 骑行接驳按居住 / 工作地格、按线路分别选沿可通行道路最近的运营车站，不为快车或绕行收益骑到同线更远的站；距离相同按稳定的车站顺序选择。步行仍可接驳其他车站。换乘站按实际第一段、最后一段乘车线路校验骑行资格，不能借另一条线的最近站资格绕过限制；车站覆盖人数同步遵守这条规则。交通模型版本为 7，旧交通缓存重算，线路和站名保留。
- 车站概况分别展示步行和骑行覆盖的居民、岗位，按到本站耗时较短的方式互斥归类，同一地块不重复计入两种方式；耗时相同归步行。两种方式都按 5 / 10 / 15 分钟累计分档，骑行档位含 5 分钟换乘，因此骑行 5 分钟内通常为零。这里统计覆盖人口和岗位，不是实际进出站客流。
- 新站自动命名依次采用附近真实站名、永久公共地标、道路名称。地标包括公园、景区、交通设施、大学及具名科学园区，不采用商场、医院、临时展会或自动生成的笼统设施；已知未开放或已停用的设施不参与命名。真实站名在 800 米内选取，道路在 500 米内按到实际线形的距离选择；重名时换用其他候选名称，最后加序号。建站预览与实际落站共用规则，已有车站和自定义站名保留。上海站名库补充 OSM 站房轮廓中的车站，包含原点状站名库缺失的闵行开发区、东川路等；可用 scripts/build-shanghai-station-names.py 从上海、江苏 PBF 重建。
- 补全闵行经开区、莘庄、浦江、金桥南北区、外高桥、康桥、松江东西区、嘉定、安亭、青浦、奉浦、东方美谷、化工区、金山、宝山、长兴、临港、洋山陆域及崇明等 25 个产业片区，并将已有张江、漕河泾、紫竹、G60、科技绿洲改为产业就业统计，共 30 个节点。范围优先采用 OSM 用地轮廓，其余依据官方四至与实际道路绘制简化示意，不是法定界址；配置在 data/shanghai-industrial-parks.json，可用 scripts/build-shanghai-industry.py 从上海 PBF 重建。新增片区沿用近郊 2015、远郊 2020 的游戏开放规则，不冒充园区成立年份。[官方四至清单](https://www.shanghai.gov.cn/qykbsj/20250606/101c96dc18fb4d5a8f6a1cf544a1bf24.html)。
- 产业园区汇总范围内现有岗位的实际模拟通勤：重叠岗位只归属一个园区，校园、医院和非就业用地排除；工作地与选站保持分散，不把全部员工送到中心点，不额外添加全市岗位或出行。园区详情显示岗位、工作日和周末到访、地铁比例及按岗位加权的步行覆盖。上海「设施出行需求 → 全部」包含通勤热力；园区圆点与片区热力为同一批出行的不同展示口径，不能相加。
- 上海旧档的站线、资金和进度可迁移到扩图后的坐标。交通小区扩大到 4 × 4 公里，以控制全市客流计算规模。
- 全市道路、水域和绿地由同一套 OpenStreetMap 地理资料生成。从 2020 年起，全图开发状态与底色按同一套人口、岗位密度及住宅用地规则计算，消除旧存档在原图内外不同的街区标记造成的矩形色块；「设施出行需求」图层按相邻交通小区插值显示，实际设施圆点仍标在原址。
- 商圈、大学城、科创园区和景区按实际地块与地址标注，启用同时受营业时间与游戏片区开放时间限制。示例：[五个新城商业布局](https://www.shanghai.gov.cn/202121bgtwj/20211109/4af3023516064702ab9b282ccf97f07a.html) · [松江大学城、科创云廊与朱家角范围](https://www.shanghai.gov.cn/gwk/search/content/cf46474f-4259-4087-ada5-105e2ec94971) · [松江印象城](https://www.songjiang.gov.cn/xwzx/001001/20210908/db9d976d-aa2c-43d9-9f0e-e8e91c93983a.html) · [紫竹高新区](https://mhjrkjpt.shmh.gov.cn/park/item/8) · [上海文旅景区](https://service.shanghai.gov.cn/sheninfo/specialdetail.aspx?Id=2ab707d3-5c68-40c3-9a54-87f96f8dedf0)。
- 枢纽面板显示工作日市内接驳出行估算（到达、离开合计）。参考普通日到发和年吞吐量，按需要扣除不进城的中转，游戏再计算地铁比例；未来客流属于模拟。依据：[虹桥站客流](https://www.shanghai.gov.cn/nw31406/20261016/162f550955194587a0560f20f177f30e.html) · [上海南站](https://www.shanghai.gov.cn/nw15343/20250106/a3f0f09f93b54255a863b34ba9fd8d8c.html) · [上海松江站](https://www.shanghai.gov.cn/nw4411/20241227/bc93ea86a3df41a3aa418d7cf7b283bb.html) · [安亭铁路枢纽](https://www.shanghai.gov.cn/nw15343/20250709/5871083de0f744a9963dfd77120b759d.html) · [上海东站站场公示](https://ghzyj.sh.gov.cn/cmsres/48/486e0f641aac411893cf8d40e98e821e/b028f7aeb310e728b4c0723d254d6200.pdf) · [宝山站规划](https://ghzyj.sh.gov.cn/bs/20250527/6f0d0307bdca44e19214d58d9224e799.html) · [上海机场 2025 年报](https://star.sse.com.cn/disclosure/listedinfo/announcement/c/new/2026-04-30/600009_20260430_BK10.pdf)。崇明国际机场是游戏设定：2035 年启用，其工作日市内接驳量和同年虹桥机场相同。

## 你可以做什么

- **选择城市与年代。** 十一座真实城市加一张青湾教程地图，各有地形、发展阶段与本地目标；自由建造还可以选择起始年份、解锁全图。
- **规划自己的路网。** 建设地下、地面和高架线路，设计曲线、环线、支线与分层换乘，调整站台方向，拆分或贯通线路。草案可以预览、撤销，确认后投入运营。
- **经营一座城市的地铁。** 选择无限资金，或在经营挑战中平衡建设、运营、票款、拨款与债务。用客流、拥堵、步行覆盖和建设效果报告判断下一步。
- **跟着城市一起发展。** 新城区、机场、校园和景区随年代启用，历史事件影响出行与经济；完成设施接驳任务，查看阶段总结和城市纪事。地图外机场在边界外显示方向、距离与客流，把线路接到边缘接驳口即可服务。
- **观察路网里的生活。** 在 2D、2.5D 与地下视图中切换，跟随列车进站，观察街头人车、城市地标与夜景。环境音随镜头所在区域变化。

- **让地铁改变城市。** 车站开通后，居民的出行习惯逐步转向地铁，新增人口和岗位更多地向站点聚集。用“拥堵变化”和“地铁带动”图层观察长期效果。
- **开发和装饰车站。** 建设广告与便利店、商业街、站城一体开发，增加非票务收入；为车站选择风格、主题色、公共艺术和标识。
- **听见乘客的反馈。** 在“地铁圈”查看与当前模拟数据对应的乘客动态、回复和满意度，关注市民，跨月观察变化。十一城提供 22 个可自行接受的城市规划难题。

- **管理车队与交路。** 56 款车型按城市和年代开放，可购买、调配和出售；按早高峰、平峰、晚高峰、夜间调度列车，环线可分方向安排。选择 40–120 km/h 线路速度，开行快车与区间车。
- **用地铁芯管理线网。** 在右下角打开总览、线路、车站、列车和票价管理，查看趋势、地图和各区段满载率；车站支持批量改规模、商业开发和装修，贯通、拆线后的趋势随线网调整。持续过载可定位或自动处理。
- **承担政府合同与经营风险。** 经营挑战达到条件后可投标新线 PPP、铁路＋物业和扩容项目，按建设与运营考核收款。车站商业计入维护成本与经济周期，低客流开发也可能亏损。
- **完成复合目标。** 任务会同时考核网络、覆盖、运营、收支或发展；截止时主体达标可获部分奖励。设施启用过晚时顺延，停用设施子项免考核；票价不足时提示恢复要求。旧任务保留已有进度。
- **使用十二种图层与四个工具。** 新增通勤时间、乘地铁比例、商业开发、测距、线路标注和任务标记；支持多选／框选拆除与一次撤销。
- **读懂城市特色与总评。** 在城市特色页查看历史规则、时间线与规划提示；历史阶段结束后生成本局总评，可导出海报。后期可建设超大型车站。
- **连接深圳与香港。** 将运营线路接到口岸，管理跨境附加费与客流，保存后切换到对岸同模式进度，并查看对岸线网。
- **回看线网成长。** 在线路图中按年月回放已确认的建设与拆除，暂停、拖动时间轴或平移缩放；历史随本局存档保存，旧档从已有记录开始回放。

支持简体中文、繁体中文和 English，可在「设置 → 画面 → 界面语言」中切换。桌面与手机均有对应界面，手机默认界面更紧凑，可在设置中调整大小；触屏支持拖动和双指缩放。

进入地图时，城市大图作为载入背景，LOGO 沿笔画逐段绘成，车站依次亮起；下方线路进度条显示城市、交通与出行的准备进度，并跟随系统的减少动态效果设置。

## 运行与存档

打开[游戏网站](https://city-and-metro.pages.dev)即可游玩。也可以下载本仓库，在桌面版 Chrome、Edge 或 Firefox 中打开 `index.html`，无需安装依赖或构建。

进度和设置保存在当前浏览器，无需账号。支持自动保存、手动保存、存档改名，以及 JSON 导入导出。更换电脑、浏览器或网址前，请先导出备份。未确认的建设草案不会保存。

支持的旧存档会在升级前保留原始备份，已有站线、票制、资金、债务和历史账目继续保留。载入失败时，可在存档列表导出原始数据。

## 常用操作

按键可在「设置 → 键位」中修改，游戏内提示会同步更新。

| 操作 | 默认方式 |
| --- | --- |
| 平移 / 缩放 | 左键拖动、WASD / 方向键；滚轮、`+` / `−` |
| 工具 | `V` 选择 · `B` 建站 · `L` 绘线 · `E` 修改 · `X` / `Delete` 拆除 · `O` 测距 |
| 绘线 | 依次点击；`Shift` + 点击添加转弯点；右键 / `Enter` 结束 |
| 批量拆除 | 拆除工具中 `Ctrl` 点击多选、`Shift` 拖动框选；`Enter` / `Delete` 执行 |
| 草案 | `Ctrl+Z` 撤销 · `Ctrl+Y` 重做 · `Ctrl+Enter` 确认建设 |
| 时间 | `空格` 暂停 / 继续；`1` / `2` / `3` / `4` 切换速度；`.` 推进一月 |
| 视图 | `T` 切换 2D / 2.5D · `U` 地下 · `K` 线网图 · `F` 全图 |
